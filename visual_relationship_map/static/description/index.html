Visual Relationship Map

Visual relationship map – Zoom/Pan, Tooltip, Export PNG/SVG, stable display order.

Key Features

  • Displays maps for Sales, Purchase, Picking, and Invoice.
  • Stable node order: Sale → Purchase → Picking → Invoice.
  • Zoom, Pan, Fit; shortcuts: Esc, F, +, −.
  • Interactive tooltips; color-coded status badges.
  • Export PNG/SVG with preserved styles (inline CSS to avoid canvas errors).
  • Smart Upstream using Regex [A-Z0-9/_-]+, linking Invoice → SO/PO via invoice lines.
